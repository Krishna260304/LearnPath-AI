Build a complete, production-quality frontend for an AI-powered Personalized Learning Path Recommender platform.

IMPORTANT:
This task is FRONTEND ONLY.

Do NOT build the backend, database, authentication server, AI models, recommendation engine, APIs, MongoDB integration, or external API integrations yet.

Use mock data and local frontend state wherever backend data would normally be required.

The frontend must be designed in a way that a FastAPI + MongoDB backend can be integrated later without redesigning the UI.

==================================================
1. PROJECT OVERVIEW
==================================================

The application is an AI-powered personalized learning platform.

The system should not simply recommend courses.

It should:

1. Collect a detailed learner profile.
2. Understand the learner's goal.
3. Understand their background, interests, preferences, constraints, and learning history.
4. Determine the learner's self-reported experience level.
5. Generate a personalized diagnostic assessment for intermediate, advanced, and experienced learners.
6. Analyze strengths and weaknesses.
7. Create a verified skill profile.
8. Identify skill gaps.
9. Identify prerequisites.
10. Generate a personalized learning path.
11. Recommend courses, videos, documentation, projects, exercises, and assessments.
12. Explain why resources are recommended.
13. Track progress.
14. Continuously assess the learner.
15. Adapt the learning path based on performance.
16. Provide an AI conversational learning assistant.
17. Provide dashboards for learners and administrators.

The UI should communicate that this is an intelligent adaptive learning platform rather than a normal course marketplace.
